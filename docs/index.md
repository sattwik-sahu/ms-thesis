# IISERB MS Thesis Template

Welcome! This is the documentation for the **IISER Bhopal MS Thesis LaTeX template** — a ready-made LaTeX setup that handles all the formatting your thesis needs to follow, so you can spend your time writing instead of fighting with margins, title pages, and bibliography styles.

!!! tip "New here? Start with Getting Started"
    If this is your first time using the template, head straight to
    [Getting Started](getting-started/overleaf.md). It will have you compiling a PDF within a few minutes.

## What this template gives you

- **A pre-built title page and certificate page**, filled in automatically from a single metadata file.
- **An academic integrity disclaimer page**, already worded to IISERB's requirements.
- **Automatic nomenclature** — define a symbol once next to where you use it, and the template builds a sorted *List of Symbols and Abbreviations* for you.
- **Modern citations and cross-references** using `biblatex`/Biber and `cleveref`, so you never have to write "Figure 3.2" by hand.
- **Works identically on Overleaf and on your own computer.**

## Where to find the template

The template lives at [github.com/sattwik-sahu/ms-thesis](https://github.com/sattwik-sahu/ms-thesis). You don't need a GitHub account to use it — you can download it as a ZIP and upload it straight to Overleaf, which is what most students should do.
